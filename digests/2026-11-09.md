## 全领域重要

### 1. Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2

Anthropic 推出 Fable/Mythos 5.2，强化编码、推理与视觉；声称输出最高约快 30%，价降至每百万输入 $8、输出 $40，可选 fast mode。Fable 对公众开放，Mythos 经生命科学/网络验证计划申请。官方称这是 Amodei 呼吁放缓后首批新前沿模型，并配套强化安全测评。  
来源：https://www.anthropic.com/claude-fable-and-mythos-5-2

### 2. Google 发布 TPU 8tx 与 TPU 8i Max

Google 扩展第八代 TPU：8tx 面向机密推理与受监管场景，在硬件层保护计算中的数据与权重；8i Max 以双芯片封装加倍算力/SRAM/HBM 带宽，服务超长上下文与机架密度。同年已有四款 TPU 系统，并推进 PyTorch 与开源工具链。  
来源：https://blog.google/innovation-and-ai/infrastructure-and-cloud/global-network/tpu-8i-max-and-8tx/

### 3. OpenAI：ChatGPT Enterprise 登陆 AWS Marketplace

OpenAI 宣布企业版可经 AWS Marketplace 采购与计费，合格支出可抵扣 AWS 承诺用量，降低采购摩擦；产品能力与直销同步更新，并与 Bedrock 上的 OpenAI 模型互补。符合条件客户亦可购买医疗与金融服务版。  
来源：https://openai.com/index/chatgpt-enterprise-aws-marketplace

### 4. Claude Fable 5.2 可端到端设计可工作的电子原型

Anthropic 与 Diode 合作测试显示，Fable 5.2 能从简短需求出发完成规格、原理图、PCB、外壳 CAD 与固件，并指导工程师做出免改电路即可工作的对讲机、语音助手与掌上宠物原型；PCB Gym 得分由 25% 升至 69%。仍属原型，未经量产认证。  
来源：https://www.anthropic.com/research/claude-electronics-design
