## 设计师相关

### 6. Gemini Notebook：资料一键生成可交互站点

Google Labs 宣布 Notebook 支持用「make me a site」把笔记与来源变成交互式讲解页、数据看板或项目管理页，可新标签打开并分享；面向 18+ 网页端全球推出（含 Workspace），移动端随后。对研究与讲解型信息设计很直接。  
来源：https://blog.google/innovation-and-ai/products/gemini-notebook/interactive-sites/

### 7. Apple 重做 Mac 权限：应对本机 AI Agent「全盘访问」

macOS 27.3 beta 2 起拆分 Device Control / Data Access，新增 System & App Protection Override，引导只授权必要 App/文件夹，可「每次询问」，并在接管其他 App 时显示透明指示。直指本地 Agent 对设计与工程工作流的隐私冲击。  
来源：https://developer.apple.com/news/?id=oqng0zjk

### 8. Google Maps「Ask Maps」：AI 行程与代约本地服务

Maps 可用 Ask Maps 生成带实时路况、营业时间与「氛围」的分日行程，并分享或导出 Docs；还能搜索美甲/宠物护理等空档并代为致电商家。Android/iOS 起推，Ask Maps 扩至欧洲约 30 国，地图产品进入可执行 Agent 交互。  
来源：https://techcrunch.com/2026/11/16/google-maps-can-now-build-trip-itineraries-with-real-time-details-about-each-stop/

### 9. Anima 发布 Agentic Canvas：人与 MCP Agent 共编同一 HTML 画布

AgentGrid/Anima 推出免费浏览器设计画布：Frame 即真实 HTML/CSS，可导入 HTML、Figma 或图片；Claude、ChatGPT、Cursor 等经 MCP 读写同一页面，设计师可拖拽微调后再让 Agent 续作，导出 HTML/PNG 等，默认可本地免账号使用。  
来源：https://animaapp.com/blog/agentic/canvas/
