### 1. OpenAI、Google、微软与 Anthropic 支持 robots.txt 统一 AI 训练偏好信号

OpenAI、Google、微软与 Anthropic 宣布将尊重 IETF 推进的 robots.txt 共享「policy token」，让站点一次声明对多家 AI 训练爬虫的偏好，无需为各家单独配置。Anthropic 已采用；OpenAI 称将在未来数月落地，Google 与微软计划 2027 年支持；既有各公司专属控制仍并行。  
来源：https://openai.com/index/helping-websites-express-ai-training-preferences · https://developers.google.com/search/blog/2026/10/ai-training-control · https://www.theverge.com/tech/1023763/openai-google-microsoft-ai-scraping-standard-opt-out

### 4. Cursor 市场出现伪造 Claude Code 扩展，约五千用户曾下载

WIRED 报道，Cursor 扩展市场曾上架带后门的仿 Anthropic Claude Code 扩展约 11 小时，最多约 5000 次下载；恶意代码存在缺陷，多数设备未完全落地持久化。Cursor 与 Anthropic 均称非 Anthropic 官方渠道遭入侵，而是攻击者向 Cursor 市场发布篡改副本；官方渠道版本未受影响，Cursor 已发布修复指引。  
来源：https://www.wired.com/story/trojan-malware-targets-thousands-of-anthropic-claude-developer-systems/

### 5. OpenAI 推出 Private Intelligence：零留存与私有推理预览

OpenAI 将企业侧数据控制打包为 Private Intelligence：对符合条件的 API 工作流提供零数据留存，并以预览形式推出结合机密计算的 Private Inference，强调提示与回复在推理过程中的保护；同时重申业务数据归属客户、代理权限与审批可由企业配置。多项能力标注「eligible」或预览，定价与适用范围未全面公开。  
来源：https://openai.com/business/private-intelligence/ · https://fourweekmba.com/ai-openai-offers-zero-retention-and-private-inference-to-firms/

## 设计师相关

### 6. Figma 发文：Weave 工作流可与 Design 画框并排复用

Figma 官方介绍 Weave：以节点串联生成、编辑与分支试错，把图像/视频创作做成可调、可复用的团队流程；并宣布 Weave 工作流可与 Figma Design 画框更紧密并存，含 Figma 节点保持布局联动。社区亦可发布 Weave 工具，让同事无需理解底层节点即可跑同一套创意流水线。  
来源：https://www.figma.com/blog/the-tldr-on-figma-weave/

### 7. 分析：Canva Brush 与 Figma 自研设计编辑模型同日对垒

FourWeekMBA 梳理：Canva 与 Figma 在相近时段各自主打「改已有设计」的专用模型——Canva Brush 称较旧设计代理最高约快 69%、单次编辑成本约低 46%；Figma 披露曾用 Llama 等底座与超 25 万条样例训练「懂 Figma 语法」的编辑模型，并在 Agent 中与第三方模型分工。对设计师意味着「生成」与「精准改稿」进一步分轨。  
来源：https://fourweekmba.com/ai-figma-trained-llama-on-250000-examples-as-canva-ships-brush/ · https://www.canva.com/newsroom/news/canva-brush/

### 8. 工程向指南：怎样把设计系统做成「AI 可读」

PedalsUp 发文指出，Figma 库整齐不等于代理可用：语义化 token、组件行为契约、Code Connect/MCP 对齐代码实现，以及可检索的工程规则缺一不可。文中建议从高频流程入手审计「稿—代码—文档」三缝，并以复用率、无障碍缺陷与返工时间衡量就绪度，避免「出图很快、维护很贵」。  
来源：https://pedalsup.com/ai-ready-design-system/

### 10. NIST 提出 AI 智能体身份与访问管理的 10 条设计原则

NIST 研究人员概述面向企业与消费场景的智能体 IAM 十条设计原则：独立可验证身份、最小权限与即时授权、策略与推理架构分离、确定性访问决策、异常监测与独立防篡改日志，以及超风险阈值时的人工复核。对设计「代理可操作」的产品与权限 UX，提供可对照的安全设计提纲。  
来源：https://industrialcyber.co/nist/nist-outlines-10-design-tenets-to-strengthen-ai-agent-identity-and-access-management-proposes-safeguards/
