### 2. METR：高权限红队揭 OpenAI 内部 Agent 监控缺口

METR 与 Redwood 在 7–8 月获深度权限，对 OpenAI 内部错位监控系统做试点红队，并于 10 月 22 日公开摘要：曾发现监控覆盖盲区、压缩事件漏检、客户端可关监控头等；OpenAI 称相关生产漏洞已修补，METR 未复测新系统。  
来源：https://metr.org/blog/2026-10-22-red-teaming-openai-agent-monitoring/

### 3. OpenAI Decisions API 全面开放：毫秒级「决策模型」

面向全客户开放 Decisions API：基于 Luna 调优，把分类/选择类推理压到约 100–180 毫秒，并加入语音与视觉模态；Box、Datadog、Ramp、Speak 等试用中替换部分 LLM 调用以降延迟与成本，对标 TypeSafe Jev 等决策模型赛道。  
来源：https://techcrunch.com/2026/10/22/openai-makes-its-jev-competitor-widely-available-as-decision-model-competition-heats-up/

### 4. Anthropic 将 Agent Skills 捐赠给 Agentic AI Foundation

Anthropic 把 Agent Skills 开放标准（含名称、logo、GitHub 组织与 agentskills.io）捐赠给 Linux 基金会下的 AAIF，与此前 MCP 捐赠同路径；称已有超 70 个 Agent 平台接入、约百万技能发布。目标是技能格式跨厂商中立演进。  
来源：https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

### 5. Microsoft 发布 MAI-DxO：逐步诊断编排冲击「医疗超级智能」

微软 AI 公布诊断编排系统 MAI-DxO 与逐步诊断基准 SDBench，相关工作刊于 *Science*：在 NEJM 复杂病例与急诊常见表现上，准确率显著高于对照医生，且常以更少检查、更低费用完成；并将与 Beth Israel 等开展真实场景前瞻评估。  
来源：https://microsoft.ai/news/building-medical-superintelligence/

## 设计师相关

### 6. Canva 发布自研图像模型 Craft：先构图再渲染

Canva Research 推出首个自研图像生成模型 Craft：两阶段先规划构图/层级/文字再出最高约 2K、30+ 画幅图；强调用模板与排版数据训练，便于 Magic Layers 拆层编辑，全站 Dream Lab 可用，并开放 API、计划接 MCP。  
来源：https://www.canva.com/newsroom/news/canva-craft/ · https://techcrunch.com/2026/10/22/canva-releases-its-first-image-generation-model/

### 7. Ideogram 推出 Vector 1.0：提示词/图片直出可编辑 SVG

Ideogram 发布首个矢量模型 Vector 1.0：文生 SVG 或图转矢量，路径可独立改色、缩放；面向 Logo、印刷与插画工作流，应用内与 API（及 fal 等）同步上线，按质量档位计费。设计师可直接导入 Figma/Illustrator 继续精修。  
来源：https://ideogram.ai/models/vector/ · https://runtimewire.com/article/ideogram-vector-1-svg-model-launch

### 8. Google 开源 Elephant-Goldfish：设计先行再写代码

Google 开源内部常用的 Elephant-Goldfish Model 插件（Apache 2.0）：长上下文「大象」只做共创与 Markdown 规格，「金鱼」零上下文对抗评审后再实现；口号「Design is the new code」，把设计文档与人机评审前置到 Agent 写码之前。  
来源：https://opensource.googleblog.com/2026/10/introducing-elephant-goldfish-model-plugin.html · https://github.com/google/elephant-goldfish-model

### 9. Etsy 收紧 AI 规则：禁售 AI 生成图案/食谱等「功能指南」

Etsy 更新卖家政策：AI 生成的缝纫/钩针图案、食谱、组装说明等功能性指南不再允许上架，且须展示真实成品照片；纯机器人批量 listing 禁止。AI 艺术仍可售，但须披露并不得冒充纯手作，回应买家对 AI「灌水」的信任顾虑。  
来源：https://www.cnbc.com/2026/10/22/etsy-bans-ai-generated-recipes-patterns-from-its-online-marketplace.html · https://www.etsy.com/seller-handbook/article/1522733284810

### 10. TypeUI：面向 AI 的 UI 微交互动效提示库

Show HN 上线 TypeUI「micro-interactions」提示合集，把按钮、列表、导航等常见界面微动效拆成可复用提示词，方便用生成式工具快速试交互节奏与反馈感；对做原型、设计系统动效规范或与 Agent 共创界面的设计师很实用。  
来源：https://www.typeui.sh/micro-interactions · https://news.ycombinator.com/item?id=50199290
