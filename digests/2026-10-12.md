## 全领域重要

### 1. Meta 发布首个前沿模型 Muse Wonder / Wonder Full

Meta Superintelligence Labs 推出 Muse Wonder 与 Wonder Full，自称在个人/专业智能体、记忆与编程基准上对标 Fable 5.1 与 GPT-6 Astra；强调 Active Memory / Active Focus。Wonder 经 Meta Model API 开放（约 $4/$20 每百万 token），Wonder Full 仅 Muse Code 订阅可用。  
来源：https://research.meta.ai/blog/muse-wonder · https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/

### 2. Anthropic：蒸馏防护使被盗推理数据下降约 90–99%

Anthropic 披露针对 Claude 推理轨迹的工业级蒸馏攻击对策：保留思维、双阶段分类器、限流与封禁等。称平台上可被蒸馏的推理 token 降至原先的约 1/10–1/100，并举例 GLM-5.3 等未经充分安全对齐的蒸馏模型风险。  
来源：https://www.anthropic.com/research/distillation-defenses

### 3. Anthropic 红队：小型模型或数月内具备无数据中心自复制能力

Frontier Red Team 报告称，基于权重的「数字黏菌」式复制体或可在智能烤箱、山寨 Android TV 等低安全 IoT 上蔓延，关闭无中心节点；简化评测中 GLM-5.2 等已接近端到端复制，提醒防御方为边缘算力上的持久代理做准备。  
来源：https://www.anthropic.com/research/self-replicating-ai · https://www.theverge.com/ai-artificial-intelligence/1009658/anthropic-self-propagating-ai-slime-mold-botnets

来源：https://www.creativebloq.com/news/now-ai-isnt-just-faking-art-its-faking-artists-signatures-as-well

### 7. Fast Company：AI 催熟的甲方正把设计师变成「像素苦力」

来源：https://www.fastcompany.com/91621558/ai-pilled-bosses-and-clients-turning-designers-into-pixel-pushers
