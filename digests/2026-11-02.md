## 全领域重要

### 1. SemiAnalysis 发布 GDPx：最强模型代理任务仅 12%

SemiAnalysis 推出覆盖芯片设计、网络安全、生物、金融等 11 个高价值领域、共 206 题的前沿代理基准 GDPx；Claude Opus 5.5 以约 12% 居首，Gemini 4 Carbon、GPT-6 Astra 紧随其后。结果显示无人监督代理仍远未可靠，验收标准需人写。  
来源：https://newsletter.semianalysis.com/p/gdpx-measuring-frontier-model-capabilities · https://gdpx.semianalysis.com/

### 3. 韩国 2027 预算：AI 与三超大项目投入 21.3 万亿韩元

总统李在明在国会提出创纪录总预算，其中半导体、具身 AI、AI 数据中心等约 21.3 万亿韩元（近翻倍），另拨约 4.7 万亿打造「世界最高性能」主权前沿模型，并推进公共 AI 代理与芯片人才培训。

### 4. AWS：GPT-6.1 Terra 上 Bedrock，Step Functions 变 MCP 工具

OpenAI GPT-6.1 Terra 在 Amazon Bedrock 全面可用，定位日常负载，据称比同系 Sol 等至少便宜约 50%，支持最长约 100 万输入 token。Step Functions 工作流可经 AgentCore Gateway 以 MCP 暴露给智能体，由编排引擎保证既定步骤顺序。  
来源：https://aws.amazon.com/blogs/aws/aws-weekly-roundup-gpt-6-1-terra-on-bedrock-step-functions-as-agent-tools-and-more-november-2-2026/

### 5. OpenAI 公开 LifeVal：衡量日常事务代理能力

OpenAI 发布 LifeVal，基于时间使用调查与约 3995 人调研，覆盖托育、政务、理财、购物等日常任务，用以驱动个人助理能力。公司自报 GPT-6 Astra 平均奖励约 80.6%（对照 GPT-5.2 约 49.3%）；任务集与跨厂对比未公开。  
来源：https://openai.com/index/lifeval

## 设计师相关

### 6. Framer Harness 2：流式执行 Agent 代码，整段工作流一次完成

Framer 重构 Agent harness，让模型用 JavaScript 表达整段工作流，并在生成未完成时按 AST 分片边写边跑，画布可即时看到修改；失败可提前取消后续生成。官方称工具步数约减半、缓存输入 token 约少 39%，成本最高降约 33%。  
来源：https://www.framer.com/blog/harness-2/

### 7. Figma Shader：最高 4096px 导出，并可进入 Code Layers

来源：https://www.figma.com/release-notes/

### 10. Canva Brush 深读：用写代码改设计，而非刷像素

The New Stack 详解 Canva 面向 Pro 的 Brush：视觉—语言模型读懂版面结构，以代理循环写并执行小段代码做编辑、再自检结果，元素仍可人工改。相对纯生图，更利于品牌改版与可控迭代，被视作垂直设计厂规避通用大模型内卷的路径。  
来源：https://thenewstack.io/canva-brush-design-editing/
