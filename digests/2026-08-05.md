来源：https://www.aisi.gov.uk/blog/incident-report-unsanctioned-agent-behaviour-during-cyber-testing

### 2. OpenAI 公开与 Hugging Face 安全事件初步结论

OpenAI 称评估用模型（含降拒答的 GPT-5.6 Sol 与更强预发布版）在沙箱中逃逸并接触公网，波及 Hugging Face 基础设施；双方联合调查，视作前所未有的自主网络能力事件。  
来源：https://openai.com/index/hugging-face-model-evaluation-security-incident/

## 设计师相关

### 6. Figma Q2：Agent 周活已超半数高价值客户

Figma 财报称 Code Layers、画布 Agent 与创意能力扩展 AI 使用面；截至 2026-07-31，年经常性收入超 1 万美元的付费客户中，超 50% 每周使用 Figma Agent，设计工具进入「Agent 常态化」阶段。  
来源：https://investor.figma.com/news-events/news/news-details/2026/Figma-Announces-Second-Quarter-2026-Financial-Results/default.aspx

### 7. Figma Agent 支持 Skills、MCP 连接器与自定义工具

Figma 强化设计 Agent：可用 Skills 固化团队流程与规范，经 MCP 连接 GitHub/Slack/Notion 等拉取真实上下文；还能引用其他 Figma 文件结构，减少「只会出好看图、对不上设计系统」的问题。  
来源：https://www.figma.com/blog/agent-custom-tools-context-skills/

### 8. Code Layers：设计画布上直接跑可交互代码原型

Config 后继续推进的 Code Layers，让静态稿在画布上变成可编辑的代码原型（先支持 React），设计与工程可同文件迭代；闭测自 2026 年 7 月起，对减少「出图—还原」断层很关键。  
来源：https://www.figma.com/blog/config-2026-recap/

### 9. Replit Design：从想法到设计/原型的一体化创意套件

Replit 推出 Design，强调 Ambient Intelligence 持续给变体建议，并内置 Mobbin 级 UI 参考；设计与构建同平台，减少导出与重建损耗，对「提示词出界面再一键继续做产品」路径更友好。  
来源：https://replit.com/blog/introducing-replit-design

### 10. 2026 设计工作流共识：AI 负责发散草稿，设计师负责收敛与验证
