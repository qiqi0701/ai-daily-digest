来源：https://techcrunch.com/2026/10/28/trump-doe-loans-5b-to-nuclear-plants-that-will-power-data-centers/

### 5. Nvidia 开源发布 Nemotron 3.5 Transcribe 语音转录模型

Nvidia 发布免费开源权重的 Nemotron 3.5 Transcribe，可覆盖约 40 种语言、最长约 1 小时录音、区分最多 8 名说话人，并同步更新 Granary 2 语音数据集；面向会议与医疗等场景，可在单芯片上运行，但不支持直播流。  
来源：https://techcrunch.com/2026/10/28/voice-ai-in-vogue-nvidia-releases-new-open-transcription-model/

## 设计师相关

### 6. Google Connected Apps：在 Gemini / Search 里直接调用 Canva 等应用

Google 开放 Connected Apps Platform 预览，开发者可通过 MCP / AppFunctions 提交应用，让用户在 Search 与 Gemini 中安全连接第三方服务并执行动作（如用 Canva 做海报、用 YouTube Music 建歌单）；美国开发者可申请，现有合作方包括 Adobe、Canva 等。  
来源：https://techcrunch.com/2026/10/28/as-ai-agents-reshape-the-web-google-opens-gemini-and-search-to-more-apps/

### 7. Cursor Design Mode 新增 Annotate：在真页面上圈选后指挥 Agent

Cursor 在 Agents Window 浏览器中推出 Annotate（约 3.24.18+）：可点选元素、框选区域、就地改文案或改 CSS，并把截图与结构上下文发给 Agent 改代码；支持批量钉注与口述备注，把「用话说布局」改成「在画面上指着改」。  
来源：https://cursor.com/docs/agent/design-mode · https://aipicks.jp/news/20261028-cursor-ai-annotate-3-24-18

### 8. Apple Creator Studio：Keynote / Pages 智能助手与 Pixelmator Generate Fill

Apple 为 Creator Studio 订阅者更新创作套件：Keynote、Pages、Numbers 引入理解文档上下文的智能助手（可助排版、动画、撰稿与图表），并支持 MCP 供外部 Agent 读写；Pixelmator Pro 新增 Generate Fill，可用自然语言改选区，偏设计生产向。  
来源：https://www.apple.com/newsroom/2026/10/apple-creator-studio-adds-powerful-new-ai-features-and-even-more-creative-tools/

### 9. Figma：生成式插件与 Shader 支持版本历史与一键回滚

Figma 为 generative plugins 与 shaders 加入版本历史：每次编辑会保留旧版，并由 Agent 生成变更说明形成 changelog，同时标明当前已发布版本，便于迭代自定义工具时恢复「改坏之前」的状态；本周起陆续推送。  
来源：https://www.figma.com/release-notes/

### 10. SpAItial Echo-3：手机扫一圈生成可度量的真实尺度 3D 空间

SpAItial 发布 Echo-3 与配套 iPhone App：用几分钟手机环拍即可重建高保真、真实尺度的 Gaussian Splat 场景，可浏览、测距并以链接分享；模型会补全未拍到的区域，面向空间叙事、地产可视化与 Agent 场景理解等设计/空间工作流。  
来源：https://spaitial.ai/blog/echo-3-release
