## 全领域重要

### 1. OpenAI：欧盟 ChatGPT/Codex 文本开始加隐形水印

为符合《欧盟 AI 法案》透明度义务，OpenAI 将在未来数周为欧盟地区 ChatGPT 与 Codex 输出嵌入不可见文本水印（textGrain）；全球 API 可按模型自行开启且默认关闭。水印靠微调用词留下可检测统计信号，短文、改写与翻译会削弱检出率。  
来源：https://openai.com/index/eu-text-provenance · https://techcrunch.com/2026/10/05/openai-will-start-watermarking-chatgpts-text-in-the-eu/

### 2. Reflection 发布开放权重推理模型 Beam

Reflection AI 正式推出首款前沿开放权重模型 Beam：文本 MoE，强调推理、编程与智能体任务，自称在高级推理基准上接近 Z.ai GLM-5.2，且推理算力约为对手约 1/3–1/4；权重与技术细节将于本月经云厂商与开源生态分发。  
来源：https://techcrunch.com/2026/10/05/reflection-debuts-beam-a-open-weight-ai-model-to-rival-chinese-models-at-lower-compute-cost/

### 3. Amazon Bedrock 上线 Z.ai GLM 5.3

AWS 宣布 Z.ai 的 GLM 5.3（约 7530 亿参数 MoE）以托管 API 登陆 Amazon Bedrock，面向编程与长程智能体工作负载，支持跨区推理、提示缓存及 OpenAI 兼容接口；企业客户无需自建推理集群即可调用。  
来源：https://aws.amazon.com/blogs/machine-learning/introducing-glm-5-3-on-amazon-bedrock/

### 4. Meta、微软大幅削减内部 Claude 用量

报道称 Anthropic 两大企业客户收缩 Claude：微软云部门将员工月度预算从约 10 万美元压到约 1 万美元并转向自研/OpenAI；Meta 的 Claude Code 用户约从 6 万降至 3 万，并推动 Muse Code 等自有工具，凸显供应商与客户竞合张力。  
来源：https://the-decoder.com/meta-and-microsoft-pull-back-from-claude-as-anthropic-transforms-from-partner-into-competitor/

### 5. DeepMind 推 SynthID Bio：给 AI 设计蛋白质加水印

Google DeepMind 发布 SynthID Bio，在氨基酸选择与结构微调中嵌入可检测信号，实验室测试显示水印版蛋白结合剂仍可工作；团队开源代码与数据，并探索对 AI 设计噬菌体基因组加水印，以回应生物安全与数据库污染担忧。  
来源：https://singularityhub.com/2026/10/05/google-deepmind-gives-ai-designed-proteins-a-watermark/
