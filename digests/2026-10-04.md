### 2. Google 因 AI 刷屏暂停开源漏洞赏金计划

### 4. Google 提出 RRSI：防止自改进 Agent「背题」

Google Cloud AI Research 等方法称，递归改写 harness 易把基准任务背进提示与工具逻辑；RRSI 用编辑预算收缩与严格评判器剔除任务专属硬编码，在编码、办公与工程设计等基准上，未见过任务最高可多约 4.7 分，运行 token 约少 30%。  
来源：https://the-decoder.com/google-researchers-find-a-way-to-keep-self-improving-ai-agents-from-memorizing-their-tests/

### 5. NASA×IBM 开源月球基础模型，面向极地冰与撞击坑

双方发布 NASA-IBM Lunar Foundation Model，基于约 17 年 LRO 等多源对齐数据预训练，可在少标注下适配冰探测、撞击坑检测等任务；模型与代码上架 Hugging Face/GitHub，并接入 TerraTorch。开源科学基础模型继续向行星观测扩展。  
来源：https://the-decoder.com/nasa-and-ibms-open-source-lunar-model-turns-17-years-of-orbiter-data-into-a-foundation-for-lunar-science/

### 7. Timeful：可视化改布局，本地代码双向同步并接 Agent

Timeful 以 Vue + Tailwind 为真源，画布改动直接写入本地 Git 仓库，无需导出或 AI 积分；任意编码 Agent 编辑同一文件夹后画布即时刷新。定位设计与工程同文件协作，适合把 Figma 式编辑落到可合并的生产代码。  
来源：https://www.timeful.io/  
https://news.ycombinator.com/item?id=49955578

### 8. EditUI：在浏览器里点选界面，批量交给 Cursor/Claude

EditUI 让你在运行中的网页上点击元素并写下修改意图，自动附带 DOM、类名、样式与上下文，可攒一批后整包粘贴给 Claude Code 或 Cursor。减少「截图圈点、口头描述找节点」的摩擦，把 UI 评审直接接上设计—代码 Agent 工作流。  
来源：https://www.editui.app/

### 9. Artbucket：开源品牌 DAM，给人与 AI Agent 同一套规范

Artbucket 把资产、色彩/字体规则、授权地域与版本发布做成可查询数据，经 MCP/REST/CLI/Git 服务团队与 Agent；发布前可做「是否允许在某渠道使用」校验，并附 Claude Code 插件教品牌优先流程。品牌系统从文档走向可执行的 Agent 转向层。  
来源：https://github.com/pwnera/artbucket

### 10. 用「研究→线框文档→Stitch」减少 AI 界面同质化

开发者总结：先用 Claude 深度研究与 ASCII 线框写成数十页规格，再分段喂给 Google Stitch，远好于「做个仪表盘」式空提示；仍需人工改间距与品牌，但能越过空白画布，适合原型速度优先、而非交付级视觉精修的场景。  
来源：https://dev.to/dishant0406/how-i-generate-quality-ui-designs-with-ai-in-30-minutes-4alb
