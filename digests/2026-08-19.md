### 3. Anthropic：Claude 自主设计蛋白结合剂，湿实验命中率高于行业均值

Anthropic 披露 Mythos Preview 与 Opus 4.8 在极少人工干预下编排开源蛋白设计工具，对 15 个可测靶点中的 14 个设计出有效结合剂；约 1320 个设计中 354 个结合成功（约 27%），高于常见 10–15% 命中率，并同步展示用 Opus 5 处理 NMR/LC-MS 分析。  
来源：https://www.anthropic.com/research/Claude-accelerates-protein-design

## 设计师相关

### 6. Claude Code 上线 `/design`：终端里先出 UI 画板再写代码

Anthropic 产品设计师 Nate Parrott 公布 Claude Code 早期预览命令 `/design`：可在 CLI/桌面端生成多版可编辑 artboard（复用 Claude Design 画布），选定后再让 Claude 按栈实现前端，减少「直接写码再返工」。需更新 Claude Code；仍偏耗 token，设计系统对齐需显式提示。  
来源：https://ai-rockstars.com/claude-code-design-command/  
报道：https://the-decoder.com/claude-code-gets-a-design-command-that-lets-developers-create-ui-mockups-right-in-the-terminal/

### 7. Block 开源 Berd：给 Agent 可识别视觉角色的桌面工作区

Block 将内部 Agent 桌面应用 Berd 以 Apache 2.0 开源，统一 Goose / Claude Code / Codex 等 harness；设计重点是「可见工作状态」与角色化视觉身份（Gloopies 等），让多 Agent 可辨认、可配置，设计师与工程师可在同一环境共建 Agent 体验。  
来源：https://block.xyz/inside/designing-ai-with-character-what-we-learned-building-berd  
报道：https://ainave.com/tech-news/block-open-sources-berd-a-local-first-desktop-workspace-for-multi-harness-ai-agents
