来源：https://openai.com/index/introducing-shirudo/

## 设计师相关

### 6. Figma Agent 正式进入 FigJam 与 Slides

Figma 宣布 Agent 在 FigJam、Figma Slides 付费计划全面可用：可用连接器/附件把设计稿、纪要、研究笔记拉上画布，整理脑暴、旅程图、行动项，或把脚本与 Spec 生成演示大纲与图表草稿，减少会前整理与做稿琐事。  
来源：https://www.figma.com/blog/introducing-figma-agent-in-figjam-and-slides/

### 7. Canva MCP 全面开放：代理可调设计与生成能力

Canva 取消 MCP 候补名单，开发者可直接接入；同步提供 REST API、扩展 CLI 与服务账号计费。代理可生成可编辑设计、图像/视频、抠图、Magic Layers 分层与导出，目标是把 Canva 做成产品内的「设计层」，并保留人在 Canva 内审改。  
来源：https://www.canva.com/newsroom/news/canva-mcp-update/

### 8. Canva：在 ChatGPT/Claude 里生成可编辑品牌视频

付费用户可在 ChatGPT、Claude 中用 Canva 连接器上传品牌素材与简报，经 MCP（含 Seedance 2.5 等）生成可编辑营销视频；生成前可确认分镜时间表，成片再进 Canva 剪辑。同日亦强化 Magic Layers 等侧栏编辑。  
来源：https://www.canva.com/newsroom/news/canva-mcp-video-generation/

来源：https://www.creativebloq.com/news/every-3d-artist-should-have-an-ai-assistant-maxon-says-as-it-launches-new-tools-and-agentic-licences
