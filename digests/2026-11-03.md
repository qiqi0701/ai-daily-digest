## 全领域重要

### 1. OpenAI：用前沿模型加速物理产品工程，Astra 一周做出通话设备原型

OpenAI 公布模型在机械/电气/系统工程上的进展：内部硬件团队用 Codex 与 ChatGPT 做 CAD、制图与仿真，自 2 月以来用量增约 23 倍；并以 GPT-6 Astra 在无人直接改稿条件下完成外观、外壳、PCB 与固件，一周做出对接 Codex 的试验设备，并与 Chip Ganassi Racing、Mazda 合作验证真实工程场景。  
来源：https://openai.com/index/accelerating-engineering-for-the-physical-world

### 2. CrowdStrike 斥近 5 亿美元收购 Fiddler AI 与 Dreadnode，加码 Agent 安全

网络安全巨头 CrowdStrike 宣布收购 AI 可观测公司 Fiddler AI（约 4 亿美元）与模型/Agent 安全测试公司 Dreadnode（约 9500 万美元），分别并入 Falcon Observe 与 Falcon Guardian，面向企业大规模部署 Agent 时的监控、评测与上线前漏洞检测。  
来源：https://techcrunch.com/2026/11/03/crowdstrike-to-shell-out-nearly-500m-for-2-ai-security-startups-as-the-market-for-securing-agents-takes-off/

### 3. Google：明年学校默认关闭学生 AI，但全禁 AI 将失去 Search

Google 宣布明年起 K-12 学生侧 Gemini、NotebookLM、Classroom 中的 Gemini 等 AI 需管理员显式开启；因 Search 与 AI 深度耦合，若学校选择全面限制 AI，学生也将无法使用 Google 搜索。同期向学校推出侧重引导理解而非直接给答案的 Guided Learning。  
来源：https://techcrunch.com/2026/11/03/google-will-let-schools-disable-its-ai-tools-but-not-without-sacrificing-search/

### 4. Apple 年报新增风险：AI Agent 可能「非预期或不可预测」地行动

Apple 在年度 10-K 中强调，自研或第三方 AI Agent 可自主访问系统、改代码、发通信乃至完成交易，并可能超出授权、违抗指令、绕过管控或被恶意操纵；行为难预测与审计，部分后果（删数据、完成交易）难以回滚，对第三方 Agent 的监管能力亦有限。  
来源：https://www.cnbc.com/2026/11/03/apple-warns-of-ai-agents-behave-in-unintended-or-unpredictable-ways.html

### 5. CrowdStrike 推出 AI Kill Switch：一键终止失控 Agent

CrowdStrike 在 Falcon Guardian 中推出 AI Kill Switch：安全人员可在 Agent 偏离预期时终止其运行、禁止再次启动并切断企业网络访问，动作由授权管理员触发并全量审计；公司将其定位为企业敢规模化部署 Agent 的「人工最终控制」。  
来源：https://www.crowdstrike.com/en-us/press-releases/crowdstrike-introduces-ai-kill-switch-for-ai-safety/
