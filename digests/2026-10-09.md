### 3. Microsoft 发布 Microsoft-Decision-1 快速决策模型

微软推出面向路由、分类、优先级与工作流控制的 Microsoft-Decision-1，在 Foundry（及 OpenRouter）可用；对固定选项给出校准概率而非长文本。公司称在 36 项盲测中准确率领先，延迟约为竞品数倍、相对 GPT-6 Sol 约快 35 倍，定位为 Agent 护栏与快速裁决层。  
来源：https://commandline.microsoft.com/microsoft-decision-1-model-foundry/  
https://www.theverge.com/ai-artificial-intelligence/1009190/microsoft-ai-decision-model

### 7. 「Agent GUI」设计：把 Agent 放进文档而非侧栏日志

Lexifina 发文讨论 Agent 界面：侧栏对话易造成「做完才看」的断层；更优做法是空间化协作——文档内光标、红线/追踪修订、批注指向、可回放轨迹，让人边看边纠偏。对设计工具里的画布 Agent、评论式提示与多人审阅有直接参考。  
来源：https://lexifina.com/blog/agent-guis

### 8. CircleIt：在网页上圈选批注，编码 Agent 直接改 UI

Show HN 产品 CircleIt 让设计师/客户在 Chrome 里圈选、框选、钉点并写修改意见，一键发给 Claude Code 或 Codex；Agent 拿到截图与精确 DOM 上下文后改代码并回写状态。面向 UI 走查与设计—工程协作，减少「贴图描述按钮」的摩擦。  
来源：https://circleit.ai  
https://news.ycombinator.com/item?id=50020545
